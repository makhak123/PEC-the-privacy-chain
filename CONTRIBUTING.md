# Contributing to Privacy Chain

Thank you for your interest in contributing to Privacy Chain ($PEC)!

## Development Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/privacy-chain.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature`

## Code Style

- Use ES6+ features
- Follow existing code formatting
- Add comments for complex logic
- Write descriptive commit messages

## Testing

Before submitting a PR:
- Test all CLI commands
- Verify blockchain validation
- Check privacy features work correctly
- Ensure no breaking changes

## Privacy Features

When contributing privacy features:
- Maintain zero-knowledge principles
- Ensure cryptographic security
- Document privacy guarantees
- Add appropriate tests

## Pull Request Process

1. Update README.md with any new features
2. Update documentation as needed
3. Ensure all tests pass
4. Request review from maintainers

## Security

If you discover a security vulnerability:
- DO NOT open a public issue
- Email security@privacychain.dev
- Allow time for patch before disclosure
